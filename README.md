# Portfolio Website 🌐✨

Live Demo: https://normiecodes.github.io/Portfolio/

This is my first personal portfolio website built using **HTML + CSS**.  
It showcases my introduction, skills, projects I am working on, and contact links.

---

## 📌 Features

- **Fixed Navigation Bar** with smooth section navigation
- **Hero Section** with profile image and introduction
- **About Me Section** describing my current roadmap and interests
- **Skills Section**
  - Desktop layout with a clean grid structure
  - Mobile layout with horizontal scrolling cards to reduce vertical clutter
- **Projects Section**
  - Card layout with descriptions of ongoing projects
  - Mobile layout with horizontal scrolling project cards
- **Contact Section** with social links

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- Responsive Design using **Media Queries**

---

## 📱 Responsive Design

The website is optimized for both desktop and mobile screens.

- Desktop: Grid-based layouts for Skills and Projects
- Mobile: Horizontal scroll layout for Skills and Projects
- Breakpoint used: **648px**
